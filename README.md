# PS2-Know-Ledge-Hub-
PS2 Know Ledge Hub® é uma enciclopédia interativa e não-oficial sobre o PlayStation 2: história, hardware, modelos, jogos, acessórios e curiosidades — tudo pesquisável, com filtros, comparador de modelos/jogos e um quiz de conhecimentos. Cada informação vem com a fonte indicada. Projeto de fã, sem vínculo com a Sony.
